# Security policy

This is a Stellar testnet pilot. It is not approved for mainnet funds or multi-tenant production use. Do not send real sponsor funds to an account configured for this pilot.

## Report a vulnerability

Please do not publish exploit details, credentials, private transaction data, or a live attack in a GitHub issue. Use GitHub private vulnerability reporting for this repository if available. If that option is not shown, contact the organization maintainers privately through GitHub to arrange a confidential reporting channel.

Include the affected repository, version or commit, a minimal synthetic reproduction, and the impact. Never include a live signing key or real user data.

## Supported versions

Only the latest tagged release and the current `main` branch receive security fixes. No response-time guarantee is offered during the pilot.
